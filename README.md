# 美股 · A股 · 港股 · 加密 桌面看盘 + 选股/评估

一个**零依赖**的桌面行情监控、因子选股与综合评估工具。用 Python 标准库（Tkinter）编写，
免费、免密钥，支持 A股/ETF/港股/美股/加密货币，数据来自新浪/腾讯/东方财富/Binance/OKX/Yahoo 的公开接口。

> 仅供学习与监控参考，**不构成任何投资建议**。

---

## 功能特性

### 📊 自选盯盘
- **多市场混排**：美股 / A股（沪、深、北）/ 港股 / ETF / 加密货币，一个列表统一盯
- **7 大指数**：上证指数、深证成指、创业板指、恒生指数、道琼斯、纳斯达克、标普500
- 现价、涨跌额、涨跌幅、**昨涨幅**、**涨幅差（今日−昨日）**、开盘、最高、最低、昨收、成交量、更新时间
- 自动识别代码市场，红涨绿跌着色（可切换为美股习惯的绿涨红跌）
- 双击任意行打开详情页（美股→雪球，A股/港股→腾讯）
- **右键菜单**：复制代码 / **查看分笔成交**（A股/港美股/加密）/ **综合评分/买入区间** / 查看公告消息（A股）/ 查看24h资讯
- **点击表头排序**：现价、涨跌幅、成交量等任意列，升/降序切换
- **币安风格深色界面**：`#0B0E11` 深底 + `#F0B90B` 强调色，标签页/表格/按钮/弹窗统一配色
- **结果导出**：选股器与因子选股结果可一键导出 CSV（UTF-8-BOM，Excel 直接打开）

### 🔍 选股器（A股 / 美股 / ETF）
- **市场选择**：A股 / 美股 / ETF，筛选条件随市场自动切换
- A股：**涨幅区间**、**量比下限**、**换手率下限**
- 美股：**涨幅区间**、**成交额下限（百万美元）**、**市值下限（亿美元）**（Yahoo 美股池，不可达时回退东财；与因子选股同源）
- ETF：**涨幅区间**、**成交额下限（亿元）**、**换手率下限**
- **当日 vs 昨日对比**（量化筛股）：
  - **昨日涨幅区间**（如昨日涨 1%～4%，找「昨日温和放量、今日加速」的启动形态）
  - **连涨天数 ≥ N**（含今日，趋势持续性过滤）
  - **仅看涨幅加速**（今日涨幅 > 昨日涨幅，即动量加速度为正）
- **24h 消息面**：每只候选抓取近 24 小时资讯，关键词标注利好/利空，展示「利好N·利空M」；
  可勾选 **仅看24h有利好** 过滤，并作为因子参与开盘倾向打分
- **买入候选颜色分层**（黄底高亮）：4 项多头条件**共振计数**——开盘倾向≥60 / 涨幅加速（今日>昨日）/
  连涨≥2天 / 24h无利空——命中 **3 项浅黄底、4 项深黄底**；新增「买入信号」星标列（可排序），
  可勾选 **仅看买入候选(≥3项共振)** 只留高亮行
- 结果展示：现价、涨跌幅、昨涨幅、涨幅差（今日−昨日）、连涨、**24h消息**、量比、换手率、成交额、成交量、行业、开盘倾向
- 排序：下拉框（量比 / 换手率 / 涨跌幅 / 昨涨幅 / 涨幅差 / 连涨 / 24h消息 / 成交额 / 开盘倾向）或点击表头升/降序
- 导出：点「导出CSV」保存当前全部筛选结果（含行业、量比、换手率、开盘倾向、买入信号）
- 美股量比/换手率由 Yahoo 的 10 日均量与总股本计算（回退东财对应字段）
- 分页：每页 20/50/100 条，支持上一页/下一页/跳转
- 渐进式渲染：结果先出现，行业字段随后补齐

### 🧪 因子选股（个股/ETF/加密，独立标签页）
- **42 个通用量价因子**：动量、趋势、波动、流动性、形态、市场六大类；
  含 5/10/20/60 日收益、剔除 1 日动量、MA 偏离、RSI、MACD、已实现波动、ATR、
  最大回撤、偏度峰度、量比、量能趋势、Amihud、量价相关、OBV、MFI、收盘位置、
  影线、Beta、指数相关、残差动量等
- **RankIC / ICIR 统计**：逐日横截面 Spearman 秩相关；按覆盖率、|IC|、t 值、
  方向一致性筛选；自动剔除高相关因子
- **样本外检验**：前 70% 交易日训练权重，后 30% 交易日只做评价，并给出等权基准对比
- **因子得分**：入选因子按权重做横截面分位加权，映射到 0～100；
  同时展示动量/趋势/波动/流动性/形态/市场六个子分和主要贡献因子
- **市场可选**：个股+ETF / 个股 / ETF / 美股 / 加密货币；成交额前 N（150/300/500）；支持 1 日/5 日预测周期
- **MA均线筛选**：全部 / 站上或跌破 MA5、MA10、MA20、MA60；结果表新增「均线」列
- **成交量筛选**：当日量 / 前 2 日量；可选 ≈1倍(0.8~1.2)、0.5~1.5倍、放量≥1.5倍、
  放量≥2倍、放量≥3倍、缩量≤0.8倍
- **量能回测**：点「量能回测」查看「当日量/前2日量」分桶与阈值的历史 RankIC、命中率、超额，
  辅助判断放量多少倍才有统计意义（见下文）
- **次日买入标注**：强候选 / 候选 / 谨慎候选 / 观察 / 回避；可勾选「仅看买入候选」
- 结果可排序、双击打开详情、右键复制代码/查看资讯/公告
- 研究性质，**不是回测**：历史 IC 使用今日成交额股票池，存在选择/幸存者偏差

> 幻方量化官网（high-flyer.cn）与 GitHub **没有公开任何因子定义或因子库**；
> 其官网只公开了「数据是 Alpha 的根本来源」「策略全面 AI 化」等方法论
> （参考 <https://www.high-flyer.cn/fund> 与 <https://www.high-flyer.cn/blog/>）。
> GitHub 同名 `High-Flyer` 账号无公开仓库；`deepseek-ai` 下是 3FS、FlashMLA、
> smallpond 等 AI 训练/推理基础设施，与选股因子无关，故未集成。
> 本模块借用其公开方法论框架，**具体因子均为通用公开量价因子，不代表幻方量化专有因子**。

### 🧾 综合评估（独立标签页，个股/ETF/加密）

顶部新增与「因子选股」同级的 **「综合评估」标签页**：输入代码（AAPL / 600519 / 510300 / BTC / cr:PEPE）后回车或点「评估」，提供 AAPL、600519、510300、BTC 快捷按钮，并支持「复制报告」。

原来的**右键 → 综合评分/买入区间**弹窗继续保留；因子页选中一行后也可点「评价选中」。

评估内容包括：

- **基本面**：PE、PB、总市值、换手率、52 周区间、行业；美股额外补 **Nasdaq 行业/目标价/平均量 + SEC 营收增长/净利率/ROE/EPS**
- **消息面**：近 24h 利好/利空/中性条数 + 最新资讯；美股合并 Yahoo 新闻与东财资讯
- **技术面**：MA5/10/20/60、RSI14、MACD、ATR%、20 日波动、20/60 日支撑压力、布林带、趋势
- **综合评分**：技术面 + 估值 + 消息面 + 因子标注（0～95）
- **买入区间**：按趋势/突破/震荡/空头四种形态，用 MA20/60、ATR、20/60 日支撑压力估算
  - 同时给出**止损参考**、**目标参考**和操作建议
  - 空头趋势只给「等待企稳」区间，不鼓励追买
  - 消息面偏空/PE 偏高/综合评分偏弱时，买入区间自动下移；消息偏正且评分 ≥60 时略上移

> 加密资产没有公司 PE/PB 和公告资讯，只做技术面与买入区间；ETF 的 PE/PB 不适用，重点看规模/流动性/跟踪指数。
> 区间是研究参考，不构成投资建议；放量跌破止损或出现重大利空时应放弃计划。

## 使用说明

### 自选盯盘

在输入框输入代码，回车或点「添加」：

| 输入 | 识别为 |
|---|---|
| `AAPL` `TSLA` `BRK.B` | 美股 |
| `600519` `688981` | 沪市 A股 |
| `000001` `300750` | 深市 A股 |
| `00700` `09988` | 港股（5 位数字） |
| `sh600519` `sz000001` `hk00700` | 显式前缀（避免歧义） |
| `510300` `159915` | ETF/LOF（沪/深） |
| `BTC` `ETH` `SOL` | 常见加密货币（Binance USDT 对） |
| `cr:PEPE` `cr:1INCH` | 其他币种显式指定 |

支持批量添加：`AAPL TSLA NVDA 600519 00700`（空格/逗号/分号分隔均可）。

- **刷新间隔**：默认 5 秒，可调 3～3600 秒
- **删除选中**：多选后删除自选股
- **红涨绿跌**：勾选为 A股习惯，取消为美股习惯
- **右键行**：复制代码 / 分笔成交 / 综合评分与买入区间 / A股公告消息
- **点击表头**：按该列升/降序排序（再次点击切换方向）

### 选股器（A股 / 美股 / ETF）

1. 先在顶部选择市场：**A股 / 美股 / ETF**，筛选条件会切换：
   - A股：涨幅区间 + 量比 + 换手率
   - 美股：涨幅区间 + 成交额(百万美元) + 市值(亿美元)
   - ETF：涨幅区间 + 成交额(亿元) + 换手率
2. 设好筛选条件（A股默认：涨幅 4%～5%、量比 ≥1.5、换手率 ≥3%）
2. 第二行的「昨日对比」条件按需填写（全部留空 = 不限）：
   - **昨日涨幅**：如填 `1` ~ `4`，即昨日涨 1%～4%，配合今日涨幅 4%～5% =
     「昨日启动、今日加速」的动量延续形态
   - **连涨≥**：如填 `2` = 今日和昨日都收涨
   - **仅看涨幅加速**：今日涨幅 > 昨日涨幅（涨幅差为正）
3. 点「查询」；美股/ETF 也支持昨日涨幅、连涨、涨幅加速、24h消息、买入候选
4. 用「排序」下拉调整顺序，用底部分页翻页

> 「4%~5%」指当日涨幅落在该区间（4 到 5 个点），属于较窄的短线强势区间，
> 可按需放宽（例如改成 3%～7%）。
>
> **涨幅差**（今日涨幅 − 昨日涨幅）为正 = 涨幅扩大或跌幅收窄，即「动量加速」；
> 为负 = 涨幅收窄（冲高乏力）或调整加深。该列为百分点差，非百分比。

### 开盘倾向指标说明（横截面多因子打分）

`开盘倾向` 是一个**横截面多因子打分**（0～100 分），而非单一启发式公式。它把候选集当做一个
「当日截面」，对每只股票计算 9 个因子，各自在候选集内做**分位排名（0~1）**——分位排名天然
稳健、抗离群值、量纲统一——再按先验权重线性合成：

| 因子 | 权重 | 定义 | 逻辑 |
|---|---|---|---|
| **动量加速度** | 0.20 | 今日涨幅 − 昨日涨幅（日K） | 涨幅扩大=资金追加、动能增强→延续概率更高 |
| **24h消息面** | 0.15 | 近24h 利好条数 − 利空条数（关键词） | 隔夜/盘中利好驱动次日开盘与承接 |
| **收盘位置（尾盘强度）** | 0.15 | `(收盘-最低)/(最高-最低)` | 收在当日高点附近=尾盘强势→易高开；收在低点附近→易低开 |
| **量比（动能）** | 0.10 | 当日量能 / 5 日均量 | 量能放大=资金关注，动能更足 |
| **连涨天数** | 0.10 | 连续收涨天数（含今日，日K） | 趋势持续性 |
| **昨日量能** | 0.10 | 昨日量 / 前 5 日均量（日K） | 今日启动前一日已放量=资金提前介入 |
| **换手率（关注度）** | 0.10 | 当日换手率 | 换手充分=流动性好、参与度高 |
| **成交额（资金规模）** | 0.05 | 成交额取对数 | 资金规模大=承接更强（对数压缩重尾） |
| **日内动量（涨幅）** | 0.05 | 当日涨跌幅 | 动量延续（窄区间内区分度较低） |

权重和为 1，合成后映射到 0～100。标签判定：分数 ≥60 为「高开」、≤40 为「低开」、其余「中性」
（9 因子合成分位加权的分布集中在中位附近，60/40 约对应前 / 后 15~20%）。

#### 买入候选信号（黄底高亮）

在开盘倾向之外，对每只筛出的股票统计 **4 项多头条件的共振数**：

| 条件 | 判定 | 逻辑 |
|---|---|---|
| 开盘倾向强 | bias ≥ 60 | 综合因子排前 15~20% |
| 涨幅加速 | 涨幅差 > 0 | 今日涨幅高于昨日，动量增强 |
| 趋势延续 | 连涨 ≥ 2 天（含今日） | 不是单日脉冲 |
| 消息面干净 | 24h 无利空（利空数 = 0） | 排除消息雷 |

命中 **3 项 → 浅黄底（候选）**、**4 项 → 深黄底（强候选）**；「买入信号」列以 ★ 数量展示（可排序），
查询完成的状态栏会汇总候选数。阈值 `BIAS_HIGH / SIGNAL_CAND` 等常量集中在源码中，可自行调整。

> ⚠️ 该信号只是**当日量价与消息面共振的客观计数**，不包含估值、大盘环境、仓位管理等维度，
> **不构成买入建议**；黄底行的正确用法是「优先人工研究清单」，而非直接下单。

> **关于权重**：权重是「先验假设」。本工具离线、无历史行情库，未做 IC 检验 / 回测来估计
> 权重与因子方向；`FACTOR_WEIGHTS` 字典集中定义于源码中，便于自行调整。

⚠️ **注意**：该指标反映当日盘面强度与近 24h 消息面，**不能预测未发生的事件**（突发公告、
外盘、政策、汇率等仍会造成跳空），且消息面标注是关键词启发式。请仅作强弱排序参考，
勿当作确定性预测下单。

### 因子选股（独立标签页）

「因子选股」页与「选股器」互不影响，专门做**横截面多因子研究 + 短线筛选**。
核心实现在 `factor_engine.py`（同样只用 Python 标准库）。

#### 1. 股票池与数据

| 项目 | 来源 | 说明 |
|---|---|---|
| 个股池 | 新浪 A股列表 `node=hs_a` | 今日成交额前 N，默认排除 ST |
| ETF 池 | 新浪 ETF 列表 `node=etf_hq_fund` | 剔除货币/短融/债类等现金型 ETF |
| 美股池 | Yahoo screener `most_actives`（主）→ 东方财富美股列表（回退）→ Nasdaq | 按成交额排序取前 N；含价格/涨跌幅/量比/换手/市值/PE/PB/行业 |
| 加密池 | Binance `ticker/24hr` | USDT 现货按 24h 成交额排序，过滤稳定币/杠杆代币 |
| 日K | 腾讯 → 新浪 → Yahoo（港美股） | 腾讯前复权；新浪不回权 |
| 美股日K | Yahoo chart（主）→ 东财 kline（回退）→ Nasdaq historical | Yahoo 日线约 2 年；东财前复权可直连 |
| 加密日K | Binance `klines` → OKX `candles` | UTC 日线，去掉当日未收盘 bar |
| 指数 | A股/ETF 用沪深300；加密用 BTCUSDT | 用于 Beta、指数相关、残差动量 |

数据缓存写入 `factor_cache.json`（30 分钟 TTL，失败负缓存 10 分钟）。
首次全量 300 只约 1～2 分钟（腾讯限流时会自动熔断并回退新浪）；命中缓存后会明显加快。
因子计算已做前缀和/滑窗优化，300 只 × 250 日的纯计算约 10 秒（不含网络）。
若回退到新浪，结果页会提示「不复权日K，除权日附近因子可能失真」。

#### 2. 因子清单（42 个）

| 类别 | 因子 |
|---|---|
| 动量 | 1/5/10/20/60 日收益、5/10/20 日剔除 1 日动量、20 日最大单日涨幅 |
| 趋势 | 偏离 MA5/10/20/60、20 日趋势斜率、RSI14、MACD 柱 |
| 波动 | 5/20/60 日已实现波动、20 日下行波动、ATR14/价格、60 日最大回撤、20 日振幅、偏度、峰度、收益自相关 |
| 流动性 | 5/20 日量比、20 日量能趋势、量能变异、Amihud 非流动性、量价相关、OBV 斜率、MFI14 |
| 形态 | 5/20 日收盘位置、20 日上/下影线、20 日上涨天数占比、20 日跳空幅度 |
| 市场 | 60 日 Beta、60 日指数相关、20 日残差动量 |

因子方向**不预先假设**，由历史 IC 的符号决定。

#### 3. 权重优化与样本外检验

- **前瞻收益**：信号日 `t` 收盘出因子，`t+1` 开盘买入，持有 `h` 日（默认 `h=1`）到收盘卖出，
  即 `C[t+h]/O[t+1]-1`；避免用 `C[t]` 买入造成的不可交易偏差。
- **RankIC**：每个交易日做一次横截面 Spearman 秩相关；1 日周期逐日计算，5 日周期按 5 日步长
  取非重叠日期，避免重叠收益高估显著性。
- **因子筛选**：覆盖率 ≥50%、有效 IC 天数 ≥20、|平均 IC| ≥0.01、方向一致性 ≥55%；
  |t| 门槛随样本长度自适应（≥60 个 IC 日要求 2.0，短样本 1.5），降低 42 因子多重检验的假阳性；
  训练区间最近 20 日 IC 与整体方向相反（且 |近期 IC|≥0.01）的因子按「近期变号」剔除；
  再按因子间横截面秩相关剔除 |相关系数| >0.85 的冗余因子。
- **近期加权**：IC 序列按 60 个交易日半衰期做指数加权，权重更偏向近期风格；
  训练/测试方向发生变号的因子会被标记「样本外变号」并剔除。
- **权重**：`sign(IC) × ICIR × sqrt(覆盖率) × n/(n+20)`，再按与已选因子的平均相关性
  除以 `sqrt(1+Σ|corr|)` 做冗余惩罚，最后 L1 归一化。
- **样本外**：前 70% IC 日期训练，后 30% 日期只做评价；同时给出等权基准，
  以及 **样本外 Top20 等权组合**的累计收益、年化、夏普、最大回撤和胜率
  （计 0.15% 往返成本并剔除历史涨停；仍未考虑停牌/冲击成本，仅作因子有效性诊断）。
  另外做 **3 折滚动样本外检验**（测试窗依次落在后 50%，训练集逐折扩张），
  只有多数折 IC 为正时才算「证据正向」。
- **交易可行性**：默认剔除当前涨停股（主板 10%、创业板/科创板 20%、北交所 30%）；
  同时把「次日开盘即涨停」的样本从前瞻收益/IC 中剔除，因为这些交易实际买不到。
- **得分**：先算加权分位合成 `Σ w_i × (rank_i - 0.5)`，缺失因子按可用权重重新归一化，
  再把合成值映射为**当日候选池内的横截面分位（0～100）**；阈值 85/95 因此有明确统计含义。
  六大类子分同样按各自类内合成值做横截面分位。
- 因子表额外展示 **近 20 日 IC** 与 **IC 胜率**，便于观察因子是否近期失效。

#### 4. 使用与限制

1. 选择市场、池大小、回看天数（120/250）、预测周期（1/5 日）、得分阈值、MA均线、量/前2日条件；
2. 点「运行」，可中途「取消」；
3. 上方表查看每个因子的平均 IC、ICIR、t 值、覆盖率、方向、权重和入选/剔除原因；
   「均线」列显示如「上5,10,20 下60」（现价在哪些均线上方/下方），可用顶部 MA 下拉筛选；
   「量/前2日」列显示当日成交量 / 前 2 个交易日成交量，用于筛选放量、缩量或约 1 倍量能；
4. 下方表按因子得分排序，可点表头排序、双击打开详情、右键复制/资讯/公告；
5. 点「导出CSV」保存全部因子选股结果（得分、均线、量能、次日建议、六大类子分等）。

#### 5. 量能回测（当日量 / 前2日量）

点「量能回测」会基于本次运行的股票池与同一前瞻收益口径，统计「当日成交量 ÷ 前 2 个交易日成交量」
这一量能比率的预测能力：

- **分桶统计**：0~0.5、0.5~0.8、0.8~1、1~1.2、1.2~1.5、1.5~2、2~3、≥3 各桶的样本数、
  平均次日收益、命中率、相对全样本的超额和 t 值
- **阈值统计**：比率 ≥1.0 / 1.2 / 1.5 / 2.0 / 2.5 / 3.0 / 4.0 / 5.0 的样本表现，
  用来看「放量到多少倍」之后超额是否稳定
- **日度 RankIC / ICIR / t**：逐日横截面计算量能比率与前瞻收益的秩相关
- 窗口顶部给出基准收益、基准命中率和自动推荐阈值（在样本数足够且超额为正的阈值中选 t 最大者）

> 量能比率是**单因子诊断**，与 42 因子模型的入选因子无关；样本仍存在今日股票池的选择偏差。
> 阈值推荐只是统计参考，样本少时 t 值不稳定，不要据此机械下单。

**重要限制**：

- 幻方官网没有公开因子定义；这里的因子是**通用公开量价因子**，不是幻方专有因子。
- 个股/ETF/加密池均取自**今日**成交额排名，历史 IC 存在选择偏差/幸存者偏差，**不是严格回测**。
- 未考虑停牌、交易成本、冲击成本与滑点；次日开盘涨停样本已剔除，但盘中成交可行性仍未完全建模。
- 加密 7x24 交易、无涨跌停；日K按 UTC 日线，当日未收盘 bar 不参与，信号以最近完整 UTC 日为准。
- ETF 无个股 PE/PB，因子只用量价/流动性；现金型 ETF 已过滤。
- 全样本权重是样本内估计；样本外 IC 只用于诊断，若样本外弱于等权基准，界面会提示。
- 42 个因子 × 120～250 个日期存在多重检验风险，**不要只看单个 ICIR 下结论**。
- 腾讯限流时回退到新浪不复权日K；混合复权口径会让除权日附近的动量/波动因子产生额外噪声。
- 结果仅供研究参考，**不构成任何投资建议**。

#### 6. 次日买入标注

结果表新增「次日建议」「证据」两列，规则如下（得分为当日候选池内的横截面分位）：

| 标注 | 条件 |
|---|---|
| **★强候选** | 因子得分 ≥95（前 5%），且样本外 IC、Top20 超额为正、多数滚动折为正 |
| **候选** | 因子得分 ≥85（前 15%），且样本外证据正向 |
| **谨慎候选** | 得分 ≥90（前 10%），但样本外证据不足（含滚动折不稳） |
| **观察** | 得分 ≥60，或候选因子因波动过高被降级 |
| **回避** | 得分 <60 |
| **数据不足** | 入选因子覆盖率 <50% |

附加规则：

- 20 日已实现波动 >80%（年化）时，强候选降为候选、候选降为观察
- 当日涨幅 ≥7% 时追加「涨幅偏高」提示
- 默认剔除当前涨停股；可在页面上取消勾选
- 样本外 IC ≤0 或 Top20 未跑赢等权基准时，**不会输出强候选/候选**，最多给谨慎候选
- 盘中运行（15:10 前）因子基于最近完整交易日，收盘后运行信号更完整

> 该标注是**因子研究候选**，不是买入建议；请结合公告、指数环境、仓位和止损自行判断。

| `factor_threshold` | 结果最低因子得分（0～100，当日候选池内的横截面分位） |
| `factor_exclude_st` | 是否排除 ST/退市整理 |
| `factor_exclude_limit` | 是否排除当前涨停股（次日开盘难以买入） |
| `factor_market` | 因子市场：`all`=个股+ETF、`a`=个股、`etf`=ETF、`us`=美股、`crypto`=加密货币 |
| `factor_ma` | MA 筛选：`全部` / `站上MA5` / `跌破MA5` / `站上MA10` / `跌破MA10` / `站上MA20` / `跌破MA20` / `站上MA60` / `跌破MA60` |
| `factor_vol` | 量/前2日筛选：`全部` / `≈1倍(0.8~1.2)` / `0.5~1.5倍` / `放量≥1.5倍` / `放量≥2倍` / `放量≥3倍` / `缩量≤0.8倍` |
| `screen_market` | 选股器市场：`a`=A股、`us`=美股、`etf`=ETF |
| `factor_show_n` | 结果表显示前 N 只（20/50/100） |

### `industry_cache.json`

行业磁盘缓存，可删除（会重新抓取）。

### `kline_cache.json`

昨日指标磁盘缓存（昨涨幅 / 连涨天数 / 昨日量比），**当日有效**——隔日自动失效重抓，
可删除。抓取失败负缓存 10 分钟，避免对接口反复重试。

## 昨日对比数据说明

- 「昨涨幅」「连涨」「昨日量能」来自腾讯前复权日K；**当日盘中未定型的 K 线会被剔除**，
  保证「昨日」是最近一个已收盘交易日
- 美股交易日比北京日期晚约 1 天（收盘在北京凌晨），参照日期自动回拨 36 小时
- 新股 / 次新股日K不足 6 根时，昨日量能缺失（打分按中性处理，相关过滤条件启用时该股被排除）
