# 美股 · A股 · 港股 桌面看盘 + 选股器

一个**零依赖**的桌面行情监控与 A股短线选股工具。用 Python 标准库（Tkinter）编写，
免费、免密钥、大陆可直连，数据来自腾讯/新浪/东方财富的公开接口。

> 仅供学习与监控参考，**不构成任何投资建议**。

---

## 功能特性

### 📊 自选盯盘
- **三市场混排**：美股 / A股（沪、深、北）/ 港股，一个列表统一盯
- **7 大指数**：上证指数、深证成指、创业板指、恒生指数、道琼斯、纳斯达克、标普500
- 现价、涨跌额、涨跌幅、开盘、最高、最低、昨收、成交量、更新时间
- 自动识别代码市场，红涨绿跌着色（可切换为美股习惯的绿涨红跌）
- 双击任意行打开详情页（美股→雪球，A股/港股→腾讯）

### 🔍 选股器（A股）
- 全市场筛选：**涨幅区间**、**量比下限**、**换手率下限**
- 结果展示：现价、涨跌幅、量比、换手率、成交额、成交量、**行业**、**开盘倾向**
- 排序：量比 / 换手率 / 涨跌幅 / 成交额 / 开盘倾向
- 分页：每页 20/50/100 条，支持上一页/下一页/跳转
- 渐进式渲染：结果先出现，行业字段随后补齐

## 使用说明

### 自选盯盘

在输入框输入代码，回车或点「添加」：

| 输入 | 识别为 |
|---|---|
| `AAPL` `TSLA` `BRK.B` | 美股 |
| `600519` `688981` | 沪市 A股 |
| `000001` `300750` | 深市 A股 |
| `00700` `09988` | 港股（5 位数字） |
| `sh600519` `sz000001` `hk00700` | 显式前缀（避免歧义） |

支持批量添加：`AAPL TSLA NVDA 600519 00700`（空格/逗号/分号分隔均可）。

- **刷新间隔**：默认 5 秒，可调 3～3600 秒
- **删除选中**：多选后删除自选股
- **红涨绿跌**：勾选为 A股习惯，取消为美股习惯

### 选股器（A股）

1. 设好筛选条件（默认：涨幅 4%～5%、量比 ≥1.5、换手率 ≥3%）
2. 点「查询」
3. 用「排序」下拉调整顺序，用底部分页翻页

> 「4%~5%」指当日涨幅落在该区间（4 到 5 个点），属于较窄的短线强势区间，
> 可按需放宽（例如改成 3%～7%）。

### 开盘倾向指标说明

`开盘倾向` 是一个**技术面启发式指标**，分数 -100（倾向低开）～ +100（倾向高开），
由三部分加权合成：

| 信号 | 权重 | 逻辑 |
|---|---|---|
| **收盘位置** `(收盘-最低)/(最高-最低)` | 最高 | 收在当日最高附近=尾盘强势→易高开；收在最低附近→易低开 |
| **量比** | 中 | 量比越大动能越足→偏多 |
| **涨幅区间位置** | 低 | 越接近涨幅上沿越强 |

标签判定：分数 ≥15 为「高开」、≤-15 为「低开」、其余「中性」。

⚠️ **注意**：该指标只反映当日盘面强度，**无法预测隔夜消息面**（公司公告、外盘、政策、
汇率等都会造成跳空）。请仅作强弱排序参考，勿当作确定性预测下单。

### 行业

`行业` 列来自东方财富 F10 的**申万二级行业**（如 白酒、半导体、通信设备），
静态属性，抓取一次后写入磁盘缓存永久复用。

| 用途 | 数据源 | 说明 |

- 免费、免密钥、大陆直连
- 行情为**延时行情**：A股盘中约 3 秒，美股/港股约 15 分钟
- 东财 `push2.eastmoney.com`（列表接口）对高频请求限流，本工具已刻意绕开

## 配置文件

### `stock_monitor_config.json`

```json
{
  "watchlist": ["AAPL", "MSFT", "600519", "00700"],
  "interval": 5,
  "cn_color": true
}
```

| 字段 | 含义 |
|---|---|
| `watchlist` | 自选股代码列表（可手改） |
| `interval` | 自选股刷新间隔（秒） |
| `cn_color` | `true`=红涨绿跌，`false`=绿涨红跌 |

### `industry_cache.json`

行业磁盘缓存，可删除（会重新抓取）。
