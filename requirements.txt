# ============================================================
# 本项目核心零第三方依赖，无需 pip 安装任何包。
#
# 运行只需 Python 3.x 自带的标准库：
#   tkinter           图形界面（Windows/macOS 的官方 Python 已内置）
#   urllib.request    网络请求（腾讯/新浪/东财接口）
#   json / os / queue / threading / time / webbrowser
#   concurrent.futures 并发抓取
#   importlib.util / shutil  问财可选依赖检测
#
# 因此核心功能直接运行即可：
#   python stock_monitor.py
#
# ------------------------------------------------------------
# 【可选】问财选股（第4个标签页）：
#   pip install pywencai
#   并安装 Node.js（pywencai 生成 hexin-v token 需要调用 node）
#   另需浏览器登录态 cookie（问财接口有同花顺风控，匿名 403）：
#     浏览器打开 www.iwencai.com → F12 → 控制台执行 document.cookie
#     → 复制粘贴到「问财选股」页的 Cookie 输入框（本地保存）
#   未安装以上依赖时，问财页仅提示不可用，其余功能不受影响。
#
# ------------------------------------------------------------
# 个别平台注意：
#   - Linux 若报 ModuleNotFoundError: No module named 'tkinter'，
#     需用系统包管理器安装 tk（非 pip）：
#       Debian/Ubuntu : sudo apt install python3-tk
#       Fedora        : sudo dnf install python3-tkinter
#       Arch          : sudo pacman -S tk
#   - Windows/macOS 的 python.org 安装包默认已含 tkinter，无需处理。
# ============================================================
